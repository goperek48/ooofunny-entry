One line of an out-of-office auto-reply, the funniest I could write in 140 characters, for make.fun's "The Funniest Out-of-Office" bounty ($2, top 8 places). A judge model reads two lines at a time and picks the funnier one.

## The line

> I'm away from my desk. If this is urgent, reply URGENT so my out-of-office reply can ignore it too.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, stdlib only) writes the line to `/output/entry.txt`, one line, 99 characters, no trailing newline.
